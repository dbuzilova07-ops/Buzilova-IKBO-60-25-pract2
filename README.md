
# Эмулятор UNIX

Практическая работа по дисциплине «Конфигурационное управление».
Вариант 2, этапы 1–3.

## Описание

Программа написана на Python с использованием Tkinter.
Представляет собой эмулятор командной строки UNIX с графическим интерфейсом.

## Реализованные функции

- Ввод и обработка команд.
- Подстановка переменных окружения.
- Команды-заглушки `ls` и `cd`.
- Команда `exit` для закрытия программы.
- Обработка ошибок при вводе команд.
- Запуск команд из текстового файла.
- Загрузка виртуальной файловой системы из папки.
- Вычисление SHA-256 для VFS.
- Команда `vfs-info` для вывода информации о VFS.

## Запуск программы

Для запуска используется Python 3 и библиотека Tkinter.

Обычный запуск:

```powershell
python src/main.py
```

Запуск с параметрами:

```powershell
python src/main.py --vfs test_folder --script tests/commands_vfs.txt
```

Параметры:
- `--vfs` — путь к папке виртуальной файловой системы.
- `--script` — путь к файлу с командами.

Также можно запустить программу через `run.bat`.

## Команды эмулятора

- `ls` — выводит переданные аргументы (заглушка).
- `cd` — выводит переданные аргументы (заглушка).
- `exit` — закрывает программу.
- `vfs-info` — выводит имя VFS, SHA-256, количество файлов и папок.

Пример ввода команд:

```text
ls
cd documents
vfs-info
exit
```

## Тестирование

Для проверки работы используются BAT-файлы из папки `tests`.

Запуск тестов:

```powershell
.\tests\test1.bat
.\tests\test2.bat
.\tests\test3.bat
.\tests\test_vfs_min.bat
.\tests\test_vfs_few.bat
.\tests\test_vfs_deep.bat
```

Проверяется выполнение команд, обработка ошибок, работа стартовых скриптов и загрузка VFS.

Используются три тестовые файловые системы:
- `vfs_min` — пустая директория.
- `vfs_few` — директория с несколькими файлами.
- `vfs_deep` — директория с вложенными папками.

## Этапы работы

1. REPL — создание графического интерфейса и базовых команд.
2. Конфигурация — добавление параметров запуска и стартовых скриптов.
3. VFS — загрузка виртуальной файловой системы и вычисление SHA-256.
